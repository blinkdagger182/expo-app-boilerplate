# Product Overview

This is a React Native mobile application boilerplate built with Expo, designed for social media functionality with camera integration, user profiles, and premium features.

## Core Features

- User authentication (email/password and OAuth)
- Onboarding flow for new users
- Camera integration for capturing and sharing photos
- Social feed with posts from friends
- User profiles with avatars
- Messaging system between users
- Friend management (requests, acceptance, removal)
- Premium subscription support via Superwall
- AI-powered image detection (cat detection)

## Target Platforms

- iOS (primary)
- Android
- Web (limited support)

## Key Services

- **Supabase**: Backend database, authentication, and storage
- **Superwall**: Paywall and subscription management
- **Expo**: Development platform and build system
